Support

The Guide for iPhone

The Guide is a reader for Wikipedia, retold with a bit more flavor. If something is broken, wrong or unkind, or you simply have a question, write to theguide@samdyatt.com.

Report a problem with an entry

Every retold entry ends with a link to report it. Please include the title of the entry. If an entry is wrong, the plain Wikipedia text is always one switch away in Settings, and the original article is linked at the foot of every entry.

Common questions

Do I need an account? No. There is no sign-in.

Where does my data go? See the privacy policy.

It is slow to load an entry. The retelling is written on demand. If it takes too long, the plain text is shown first and the retold version can be swapped in when it arrives.

I would rather nothing leave my phone. In Settings, set “Rewritten by” to “This phone” (needs a recent iPhone that supports Apple Intelligence).

Where is the rest of it? You will have to find that for yourself.
